## Presenter path
Scan equipment → Capture label → Save equipment → Report a repair → Send for review.
The seven-screen Figma walkthrough uses sample data and simulates scanning and submission. It does not access a camera, submit a real request, or accept typed form input. Use the website for actual OCR. Figma sharing permissions determine who can open the presentation link.
